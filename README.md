# LW Veículos — versão moderna

Stack:
- Next.js
- Tailwind CSS
- Supabase Database/Auth/Storage
- Vercel

Para atualizar um projeto já configurado:
1. Mantenha seu `.env.local`.
2. Substitua os arquivos do projeto pelos desta versão.
3. `npm.cmd install`
4. `npm.cmd run dev`
5. Teste em localhost.
6. `git add .`
7. `git commit -m "Atualiza visual moderno"`
8. `git push`
A Vercel fará novo deploy automaticamente.
